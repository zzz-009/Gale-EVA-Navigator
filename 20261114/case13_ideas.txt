# Case 13: Planet X and SPHEREx — アプリ提案

> **テーマ要約**: 2025年からNASAの **SPHEREx** は全天を6か月ごとに、102バンドの近赤外線で観測している。天体の位置の変化（彗星・小惑星・近くの恒星・褐色矮星など）を見つけやすくするため、**誰でも使える公開Webツール**をつくる。赤経・赤緯を入力すると、その空の画像を時系列で「小さな動画」のように表示する。
> **テスト対象**: Barnard's Star（固有運動が非常に大きい恒星）、Epsilon Indi B（恒星を回る褐色矮星のペア）、WISE 0855（高速で動く褐色矮星 RA 08h55m10.831s, Dec −7°14′42.53″）、変光星 RW Aurigae と R Draconis
> **推奨機能**: 新しいデータリリースに対応しやすい設計／102バンドの見せ方の工夫（6つの検出器アレイごとに足し合わせてS/N向上）／スペクトルのその場生成（加点）／画像の足し算・引き算／視野の選択／Gaia・WISE の重ね合わせ／URLに座標を含めて埋め込み可能に／汚染フラグなどのメタデータ表示／Astropy や Aladin の活用
>
> **技術メモ**: SPHEREx の画素は約6.2秒角と大きい。Barnard's Star（年約10秒角）でも半年で1画素前後しか動かないため、**画像の差分（引き算）や重心位置の精密測定、複数年の比較**が動きを見つける鍵になる。

---

## 案1: Sky Blink Viewer — 座標を入れるだけで「まばたき比較」動画を作る基本ツール

- **コンセプト**: 課題の必須機能を最もシンプルかつ確実に実装。座標（または天体名）を入れると、IRSA から SPHEREx の画像の切り抜きを取得し、観測時刻順に**パラパラ漫画（ブリンク）**として再生する。冥王星が発見されたときの「ブリンク比較」の現代版。
- **主な機能**
  - 入力: 赤経・赤緯（複数形式に対応）、天体名（SIMBAD で座標解決）、視野サイズ
  - 時系列アニメーション（再生速度・コントラスト調整）
  - 6つの検出器アレイごとの合成画像（バンドを足し合わせて S/N を上げる）
  - 画像の引き算モード（ある時期 − 別の時期 → 動いた天体が白黒のペアとして浮かぶ）
  - URL パラメータ（`?ra=...&dec=...&fov=...`）で共有・埋め込み
  - 汚染フラグ・観測日時などのメタデータ表示
- **使用データ**: SPHEREx 公開データ（NASA/IPAC IRSA、カットアウト / 画像アクセスサービス）、SIMBAD
- **技術スタック例**: Python（astropy, astroquery / pyvo, reproject で画像の位置合わせ）、FastAPI、フロントは JS9 または Canvas
- **差別化ポイント**: 課題のテスト対象5天体すべてでデモ動画を用意し、「確実に動く」ことを示す
- **MVP範囲（2日）**: 座標入力 → ブリンク再生 → 引き算 → URL共有
- **リスク・注意点**: 画像ごとに向き・画素配置が違うので、共通の座標グリッドへの**再投影（reproject）**が必須

## 案2: Spectral Explorer — 102バンドを「色」と「スペクトル」で見せる

- **コンセプト**: SPHEREx の最大の特徴である102バンド（0.75〜5μm）を活かす。画像上の天体をクリックすると、**その場でスペクトル**（波長ごとの明るさ）を作成。褐色矮星はメタン・水の吸収で特徴的な形になるため、「この点は褐色矮星っぽい」と判定の手がかりになる。
- **主な機能**
  - 擬似カラー合成（短い波長=青、長い波長=赤 など、バンドの割り当てをユーザーが変更可能）
  - クリックした天体のスペクトルをその場で生成（各画像の該当画素から測光）
  - 褐色矮星・恒星・銀河の代表スペクトルとの比較（テンプレート照合）
  - 時期ごとのスペクトルの変化（変光星 RW Aur、R Dra の変化を見る）
- **使用データ**: SPHEREx 画像（各画素の波長情報を含む）、褐色矮星・恒星のスペクトルテンプレート（公開ライブラリ）
- **技術スタック例**: Python（astropy, photutils）、Plotly
- **差別化ポイント**: 課題で「Extra kudos」とされているスペクトルのその場生成を実装
- **MVP範囲（2日）**: テスト5天体のスペクトル表示 + 擬似カラー合成
- **リスク・注意点**: SPHEREx は画像内の位置ごとに波長が変わる仕組み（線形可変フィルター）なので、各画素の波長をメタデータから正しく読む必要がある

## 案3: Motion Overlay with Gaia & WISE — 他の望遠鏡のカタログを重ねて「動いた天体」を自動候補化

- **コンセプト**: Gaia や WISE（CatWISE）の既知の天体カタログを重ね、**カタログにない点、カタログ位置から動いている点**を自動でハイライト。Gaia の固有運動から「今どこにいるはず」を予測して円で示し、SPHEREx 画像上の実際の位置と比べられる。
- **主な機能**
  - Aladin Lite ベースの全天ビューワー + SPHEREx 画像レイヤー
  - Gaia DR3 / CatWISE の天体を重ね表示（固有運動ベクトルを矢印で）
  - 観測時刻に合わせて Gaia の予測位置を動かす
  - 「カタログにない / 予測位置とずれている」候補リストの自動生成
- **使用データ**: SPHEREx（IRSA）、Gaia DR3、CatWISE2020 / unWISE、SIMBAD
- **技術スタック例**: Aladin Lite v3、astroquery（Gaia / IRSA）、Python バックエンド
- **差別化ポイント**: 既存天文ツール（Aladin）と組み合わせ、ゼロから作らずに高機能化。新発見のきっかけになる
- **MVP範囲（2日）**: テスト5天体周辺での重ね合わせと候補リスト
- **リスク・注意点**: 自動候補はノイズ・アーティファクトが多い。人の目で確認する前提の「候補」と明記

## 案4: Citizen Discovery Hub — みんなで動く天体を探す市民科学プラットフォーム

- **コンセプト**: Backyard Worlds のような市民科学の仕組みをSPHEREx向けに。ランダムな空の領域のブリンク画像を出し、利用者が「動いている点がある / ない」をクリックで報告。多くの人の報告が集まった点を候補として集計する。
- **主な機能**
  - 「次の空を見る」ボタン → ブリンク画像
  - 動いた点のクリック報告と、既知天体との自動照合
  - チュートリアル（Barnard's Star や WISE 0855 で練習 → 「これが動く天体です」）
  - 報告数ランキング、発見候補の一覧
- **使用データ**: SPHEREx（IRSA）、Gaia、SIMBAD（既知天体の除外）
- **技術スタック例**: Next.js、Supabase（報告の保存）、Python 画像生成
- **差別化ポイント**: 課題文の「誰か一人では全データを見られない、多くの人に参加してもらう」に応える
- **MVP範囲（2日）**: 事前に作った100領域のブリンク画像 + 報告機能 + チュートリアル
- **リスク・注意点**: ログインの手間を減らし、匿名でも参加できるようにする

## 案5: Light Curve & Variability Studio — 変光星の明るさ変化を「波長ごと」に追う

- **コンセプト**: 位置の変化だけでなく、**明るさとスペクトルの時間変化**に注目。変光星 RW Aurigae（若い星）や R Draconis（ミラ型変光星）の、波長ごとの明るさの変化（光度曲線）を描き、「どの波長で大きく変わるか」から星の物理（ちり、分子の吸収）を解説する。
- **主な機能**
  - 天体の位置を指定 → 各観測回の測光 → 光度曲線
  - 波長ごとの光度曲線を並べた表示（赤外ほど変化が大きい？などを比較）
  - 他の観測（WISE の多時期データ）と合わせて長期の変化を表示
  - 天体の解説カード（なぜ明るさが変わるのか）
- **使用データ**: SPHEREx、NEOWISE / AllWISE の多時期測光、AAVSO の光度データ（可視光との比較）
- **技術スタック例**: Python（photutils, astropy.timeseries）、Plotly
- **差別化ポイント**: テスト対象に変光星が2つ含まれている点を活かし、他チームとの差を出す
- **MVP範囲（2日）**: RW Aur と R Dra の2天体の光度曲線
- **リスク・注意点**: SPHEREx の観測は半年に1回程度（領域による）なので、測光点の数は少ない。WISE データで補う
