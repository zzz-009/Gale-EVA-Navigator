# Case 15: The Earth Information Jukebox — アプリ提案

> **テーマ要約**: NASA の **Earth Information Center（EIC）** の地球科学ビジュアライゼーションは視覚にしか頼っておらず、目の見えない人・見えにくい人には届かない。EIC の映像フレームを**リアルタイムに音へ変換（ソニフィケーション）**する「Earth Jukebox」をつくる。
> **ポイント**: ①映像フレームから色・明るさ・形・画素の密度などを解析し、音の高さ・リズム・テンポ・音量・楽器に対応づける ②データに忠実すぎると雑音になるので、音階・和音などの**音楽的ルール**で聴きやすくする ③アクセシビリティ（スクリーンリーダー対応、触覚フィードバック、詳しい説明文） ④なぜその変換にしたかの説明 ⑤気候変動の切迫感や地球の美しさなど、感情に訴える
> **成果物の形**: Web のジュークボックス、デスクトップアプリ、API、または生成した音源のプレイリスト + 制作過程の説明、のいずれでもよい

---

## 案1: Earth Jukebox Player — 映像を選ぶと音楽が流れる「ジュークボックス」本体

- **コンセプト**: 課題名どおりのジュークボックス。EIC の映像（世界の気温、海流、海氷、植生など）を選ぶと、映像のフレームを解析しながら**リアルタイムで音楽が生成**される。データ → 音のルールは映像ごとに設計し、「気温が高いほど音が高く、明るい音色に」のように直感的にする。
- **主な機能**
  - ジュークボックス風の選曲画面（映像のサムネイル = レコード）
  - フレームごとの解析: 色の分布（カラーバーの値に変換）、平均値、変化量
  - 対応ルール例: 平均気温 → 音の高さ（ペンタトニックなど不協和音になりにくい音階）、異常値の面積 → 和音の厚み、変化の速さ → テンポ
  - 「マッピングの説明」パネル（今どのデータが何の音になっているか）
  - 再生・一時停止・速度変更、キーボードだけで全操作可能
- **使用データ**: NASA EIC のビジュアライゼーション（NASA Scientific Visualization Studio の動画・フレーム）
- **技術スタック例**: Tone.js（Web Audio）、Canvas / OpenCV.js（フレーム解析）、React
- **差別化ポイント**: **映像のカラーバー（凡例）を読み取って色を実際のデータ値に戻してから音にする**ことで、「見た目の色」ではなく「データ」を聴かせる
- **MVP範囲（2日）**: 映像3本（例: 気温、海氷、植生）× それぞれの音のルール
- **リスク・注意点**: 映像ごとにカラーバーが違うため、映像ごとに色→値の変換表を用意する

## 案2: Touch & Listen Globe — 指でなぞった場所の音が聞こえる探索型インターフェース

- **コンセプト**: 映像全体を自動で音にするだけでなく、利用者が**画面を指（またはマウス）でなぞると、その場所のデータが音になる**。北極をなぞると海氷の音、赤道をなぞると気温の音。見えない人でも「どこに何があるか」を空間的に探索できる。
- **主な機能**
  - タッチ / マウス位置の画素値 → 音の高さ・音色
  - 左右の位置 → ステレオの左右（パンニング）で空間を表現
  - スマホの振動（Vibration API）で境界（陸と海など）を触覚的に伝える
  - 現在地の読み上げ（「北緯60度、大西洋、平年より2度高い」）
  - 時間スライダーで年ごとの変化を聞き比べ
- **使用データ**: EIC / SVS の気温・海氷・海面水温などの映像フレーム
- **技術スタック例**: Web Audio API、Pointer Events、Vibration API、Web Speech API、ARIA ライブリージョン
- **差別化ポイント**: 課題文の「探索的な」変換と、触覚フィードバックを含むアクセシビリティに最も強く応える
- **MVP範囲（2日）**: 映像2本、なぞり音 + 読み上げ + 振動
- **リスク・注意点**: iOS Safari は Vibration API 非対応。音と読み上げだけでも成立するように作る

## 案3: Climate Symphony — 数十年の変化を「交響曲」として聴くキュレーション作品

- **コンセプト**: 課題で認められている「生成した音源のプレイリスト + 制作過程の説明」形式。過去数十年の気温・海氷・CO₂ などの映像を、**楽章ごとに異なる楽器**で表現した作品にする。年が進むにつれて音楽がどう変わるかで、気候変動の切迫感を伝える。
- **主な機能**
  - 楽章構成: 第1楽章「大気（気温）」、第2楽章「氷（海氷・氷床）」、第3楽章「海（海面水温）」、第4楽章「全部の合奏」
  - 映像と音の同期再生（映像の年表示と音の変化が一致）
  - 制作過程の解説ページ（どのデータをどのルールで音にしたか、なぜその楽器か）
  - 音源のダウンロード（WAV / MP3）と、詳細な文章説明（音声だけでも内容がわかるように）
- **使用データ**: EIC / SVS の長期変化の映像（地球の気温変化、北極海氷の変化など）
- **技術スタック例**: Python（OpenCV でフレーム解析、mido / pretty_midi で MIDI 生成）、DAW または FluidSynth で音源化
- **差別化ポイント**: 芸術性・感情的なインパクトで審査員に強い印象を残す。技術的な難度が低めで完成させやすい
- **MVP範囲（2日）**: 4楽章 × 各1〜2分 + 解説ページ
- **リスク・注意点**: 「リアルタイム生成」ではないので、案1 の簡易版と組み合わせると課題文の両方の形に対応できる

## 案4: Sonification API — どんな映像でも音にできる変換エンジンAPI

- **コンセプト**: 映像（またはフレーム画像）を送ると、**音のパラメータ（MIDI / 音声ファイル / 音のイベント列）**を返すバックエンドAPI。変換ルール（どの色を何の音に）をJSONで設定できる。他の開発者・博物館・教育サイトが自分のサービスに組み込める基盤。
- **主な機能**
  - API: 画像/動画のアップロード → 解析結果（色の分布、明るさ、エッジの密度など）+ 音の出力
  - 変換ルールのプリセット（「気温用」「海氷用」「汎用」）とカスタム設定
  - ルール作成用のWebエディター（スライダーで調整しながら試聴）
  - OpenAPI ドキュメント
- **使用データ**: EIC / SVS の映像
- **技術スタック例**: FastAPI、OpenCV、librosa / pretty_midi、React（エディター）
- **差別化ポイント**: 課題文が挙げる「バックエンドAPI」形式。EIC 以外の NASA 画像にも広げられる拡張性
- **MVP範囲（2日）**: API 2本 + プリセット3種 + 簡易エディター
- **リスク・注意点**: APIだけではデモ映えしないので、案1の画面をこのAPIの利用例として見せる

## 案5: AI Narrated Soundscape — SIが映像を言葉で説明し、音と語りで地球を伝える

- **コンセプト**: 音だけでは「何の音か」がわかりにくい。SI（画像認識・言語モデル）が映像フレームを解析して**短い説明文を自動生成**し、ソニフィケーションの合間にナレーションとして流す。「今、北極の海氷が最小になりました」のように、音と言葉で内容を伝える。
- **主な機能**
  - フレーム解析 → 重要な変化（最大・最小、急変）の自動検出
  - 変化点での短いナレーション（読み上げ）と、効果音的な合図
  - 説明の詳しさを3段階で切り替え（初心者 / 一般 / 詳しい人）
  - 多言語対応（日本語・英語）
  - スクリーンリーダー用の詳細テキスト（オーディオディスクリプション）
- **使用データ**: EIC / SVS の映像と、映像に付属する説明文・メタデータ
- **技術スタック例**: マルチモーダル LLM API（画像の説明）、TTS、Tone.js
- **差別化ポイント**: 「リッチな説明文」によるアクセシビリティを、音楽と組み合わせて自動化
- **MVP範囲（2日）**: 映像2本、変化点ナレーション、詳しさ3段階
- **リスク・注意点**: SIが映像の内容を誤って説明しないよう、映像の公式説明文・データ値を根拠として渡す
