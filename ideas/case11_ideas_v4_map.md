## 4. 時刻の変換（月）

画面上部の「時計バー」に、次をまとめて表示する。

| 表示 | 計算方法 |
|---|---|
| 地球の時刻（UTC と日本時間） | 入力された日時 |
| **月面の地方太陽時**（例: 「午前 8 時 12 分」） | 太陽の時角から計算する。月の1日を 24 等分した「月面時間」で表示 |
| 月の1日の中の位置 | 「日の出から 3.2 地球日」「日没まで 11.6 地球日」 |
| 季節 | 太陽直下点の緯度（Horizons で取得）。「南極は今、夏（太陽が高め）」 |
| 地球の見え方 | 地球直下点の緯度・経度 = 秤動。「地球の高度は ±◯° の範囲で揺れる」 |
| 通信の遅れ | 地球までの距離 ÷ 光の速さ（約 1.3 秒） |

**南極では「地方太陽時」の意味が薄い**ことに注意してください。太陽は昇り沈みせず、地平線すれすれを一周するので、「月面の時刻 = 太陽の方位」に近くなります。UI では「太陽は今、方位 ◯° の方向」と並べて表示します。

## 8. 追加の考慮: 距離・標高・斜面の角度・磁気嵐を避ける

### 8.1 先に確認したいこと（本当にそれでいい？）— 「磁気嵐」について

**月には地球のような磁場（磁気圏）がないので、「磁気嵐」そのものは月では起きません。** 磁気嵐は、太陽からの噴出物（CME）が地球の磁場を揺らす現象です。月面で本当に避けるべきなのは、同じ太陽の活動から来る**放射線**です。

| 太陽の現象 | 地球で起きること | 月面で起きること | 避け方 |
|---|---|---|---|
| 太陽フレア（FLR） | 通信障害 | 数十分以内に高エネルギー粒子が届くことがある | 事前の予測は難しい → **すぐに逃げ込める場所を常に把握する** |
| 太陽高エネルギー粒子（SEP） | 極域の航空路への影響 | **被ばくの主な原因** | 屋外の活動を止め、避難する |
| コロナ質量放出（CME） | **磁気嵐（GST）**、オーロラ | 衝撃波で粒子が加速され、SEP が増える | **到着予測（1〜3日前）があるので、出発を延期・早めに帰還できる** |

→ このアプリでは、**「磁気嵐を避ける」=「宇宙天気（CME・SEP・フレア）による放射線を避ける」**として設計します。データは NASA の **DONKI API**（CME、GST、SEP、FLR のイベントと、CME の到着予測）を使います。地球の磁気嵐（GST）は、「同じ CME が地球と月の周辺に届いた」目印として表示します。

> 月の公転について: 満月の前後の約6日間、月は地球の磁場が後ろに長く伸びた部分（磁気圏の尾）の中を通ります。この間は太陽風が弱まります。ただし、高エネルギーの SEP は防げません。時計バーに「磁気圏の尾の中」と表示すると、正確さで加点が狙えます（P2）。

### 8.2 距離・標高・斜面の角度 — どこに表示し、どう使うか

すべて LOLA DEM から計算できるので、**追加のデータは不要**です。

| 要素 | 表示する場所 | 中身 | ルート計算での使い方 |
|---|---|---|---|
| **距離** | ルートの候補、ナビ画面 | 総距離（**地表に沿った距離** = 平面の距離 + 高低差）、残りの距離、2点間の距離の測定 | 移動効率のコスト |
| | 地図（新規） | **帰還できる範囲**: バッテリーと時間の残りで、行って戻ってこられる範囲を地図上に円のように塗る（電気自動車の「航続可能範囲」と同じ考え方） | 範囲外の目的地は警告 |
| **標高** | ルートの下の**縦断図**（Google マップの自転車ルートと同じ） | 高低差のグラフ、累積の登り・下り、最高地点 | 登りのコスト |
| | 地点の詳細パネル | **標高が高いほど地平線が下がり、日照と通信が良くなる** → 「マスト（アンテナ・太陽電池パネル）の高さ」のスライダー（2 m → 10 m）で、地球が見える割合がどう変わるかを示す | 本題（太陽・地球の見え方）との接続 |
| **斜面の角度** | 地図の**傾斜レイヤー**（4段階: 0〜5° 安全 / 5〜15° 注意 / 15〜20° 制限 / 20° 超 通行不可） | 着陸地点の判定（着陸機が許容する傾斜。初期値 10°、UI で変更可） | 通行可否、地形リスクのコスト |
| | ナビの案内 | 「300 m 先、登り 12°」「この先、**横向きの斜面 14°**（横転に注意）」 | 進む向きに対する傾き（登り / 下り / 横）を分けて計算する |

**妥当性の注意**: 20 m 解像度の DEM では、岩の1つ1つは見えません。「20 m より小さい障害物は対象外」と画面に明記してください。

### 8.3 宇宙天気（磁気嵐）を避けるための機能

| 機能 | カーナビでの例え | 中身 | 優先 |
|---|---|---|---|
| **宇宙天気バー** | 天気予報 | 時計バーに「静穏 / 注意 / 警報」を表示。DONKI の最新のイベントと、CME の到着予測 | P1 |
| **出発前チェック** | 「この先、通行止め」 | 計画中の活動時間に CME の到着予測が重なると、「出発を◯時間早める / 延期する」を提案 | P1 |
| **避難ナビ** | 近くの避難所への案内 | ボタン1つで、**いちばん近い避難場所**（着陸機、または空が狭く見える崖の下）へのルートを出す | P2 |
| **避難場所の候補レイヤー** | — | 地平線マスクから「**空の開き具合**」（空が見える立体角の割合）を計算する。崖の下や谷の底ほど、空から来る放射線の一部が地形で遮られる | P2 |
| **過去のイベントの再生** | — | デモ用に、過去の大きな CME・SEP（DONKI の記録）を再生し、ナビが帰還ルートに切り替わる様子を見せる | P1（デモの山場） |

**妥当性の注意**:
- 「空の開き具合」で放射線を見積もるのは、**放射線が全方向から均等に来る**と仮定した簡易モデルです。数値は「目安」とし、線量（mSv）は出さない方が安全です。
- SEP は事前の予測が難しいので、「予測して避ける」と言い切らないでください。「CME は予測で避け、SEP は素早く逃げる」と言い分けます。

## 付録 A: もし火星（Case 10）で作るなら

- 課題文に「ルートの地図」「3種類以上のデータの重ね合わせ」「安全」「宇宙天気」が明記されているので、**カーナビ風の機能がそのまま課題の中心になる**
- データ: Mars Trek（タイル配信は確認済み）、HiRISE の地形データ、USGS の地質図、Curiosity の走行記録（ルートの検証に使う）、DONKI（宇宙天気）
- 時刻: Mars24 のアルゴリズムで、地球の時刻 → 火星の時刻（MSD、MTC、LMST、LTST）と太陽黄経 Ls に変換する
- 計算エンジン（地形 → 傾斜 → A* → 理由の説明）は、月と共通で作れる
- 磁気嵐: 火星にも全体を覆う磁場はない（地殻の一部に弱い磁場が残るだけ）。月と同じく「宇宙天気による放射線を避ける」と読み替える。火星では薄い大気が少しだけ放射線を和らげる。Curiosity の放射線計測器（RAD）の公開データで、地表の放射線の目安を示せる
