# Case 7: Flame in Freefall — アプリ提案

> **テーマ要約**: NASAが数十年にわたり蓄積してきた**微小重力下の燃焼実験データ**（Physical Science Informatics: PSI データベース）を、SI（AI）を使って要約・ランク付け・解釈し、宇宙探査の火災安全に役立つ知見を届けるWebダッシュボードをつくる。
> **主な実験**: 固体材料の燃焼（BASS / BASS-II、Saffire-I〜III）、煙検知（SAME / SAME-R）、消火（FLEX / FLEX-2）、気体燃料火炎（ACME の6実験: CFI-G, E-FIELD Flames, BRE など）、液滴燃焼（CFI）、煤（SPICE）、浮き上がり火炎（SLICE）、粉塵（DAFT）
> **重要な文脈**: 月面基地・与圧ローバーは酸素濃度30%以上・圧力10.2 psi以下になる見込み（地球の空気より40%以上酸素が多く、燃えやすい）／部分重力（月・火星）の燃焼データはまだPSIにない
> **対象ユーザー**: 教授・大学院生・学部生・航空宇宙の研究者やエンジニア

---

## 案1: Fire Safety Relevance Ranker — 「あなたの環境」に効く実験をSIがランク付け

- **コンセプト**: ユーザーが想定環境（宇宙船 / 宇宙ステーション / 月面基地 / 火星基地 / 与圧ローバー）と条件（酸素濃度、圧力、気流、材料の種類）を入力すると、SIがPSI内の実験を**関連度順にランク付け**し、「なぜ関連するか」を根拠付きで説明する。
- **主な機能**
  - 環境プリセット（例: 月面基地 = O₂ 30%以上・10.2 psi以下、低気流）
  - 実験ごとの関連度スコアと理由（予防 / 検知 / 消火のどれに効くか）
  - 実験カード: 目的、燃料（形状・サイズ）、酸素濃度、流速、センサー、主な結論
  - 「データが足りない領域」の表示（例: 部分重力、高酸素×固体材料）
  - 引用元（PSIの実験ページ、論文）へのリンク
- **使用データ**: NASA PSI データベース（実験メタデータ・報告書）、NASA Technical Reports Server（NTRS）の関連論文
- **技術スタック例**: RAG（実験文書をベクトルDB化）+ LLM API、Next.js、構造化メタデータは手作業で正規化したJSON
- **差別化ポイント**: 課題の最初の目標「居住環境の火災安全ニーズに最も関連する研究を特定」に直接答える
- **MVP範囲（2日）**: 10〜15実験をメタデータ化、環境プリセット5種
- **リスク・注意点**: SIのランク付けは、ルールベースのスコア（酸素濃度の近さ、燃料タイプの一致など）とSIの説明を組み合わせて透明性を確保

## 案2: Experiment Matrix — 実験条件を横断比較する「パラメータ空間マップ」

- **コンセプト**: 全実験の試験条件を**「酸素濃度 × 気流速度 × 圧力」などの軸で散布図**にプロットし、どの条件がよく調べられていて、どこが空白か（研究ギャップ）を一目で示す。同じ実験内でのテスト間の違いも比較できる。
- **主な機能**
  - 軸を自由に選べる散布図（色 = 燃料の状態: 固体/液体/気体、形 = 実験装置: CIR / MSG）
  - 月面基地・火星基地・宇宙服の想定条件を「ターゲット領域」として重ね表示
  - 2つの実験を選んで共通点・相違点を並べる比較ビュー
  - 装置の共通性（ACMEはCIRの共通モジュール、BASS/SPICE/SLICEはMSGのダクト）の系譜図
- **使用データ**: PSI の実験メタデータ・テストマトリクス
- **技術スタック例**: Python（pandas）でデータ整形、Plotly / D3.js、SIで報告書から条件を抽出
- **差別化ポイント**: 課題文の「同じ調査内でテストはどう違い、どう同じか」「調査間の類似点・相違点」に視覚的に応える。研究者にとって最も実用的
- **MVP範囲（2日）**: 主要8実験のテスト条件を抽出して散布図化
- **リスク・注意点**: 報告書からの条件抽出をSIに任せる場合、抽出値の人手チェックが必須

## 案3: Flammability Boundary Explorer — 酸素濃度と気流で「燃える / 燃えない」境界を予測

- **コンセプト**: 固体材料の燃焼実験（BASS, Saffire 等）のデータから、**酸素濃度・気流速度に対する燃焼可否・燃え広がり速度**を可視化し、簡易的な予測モデルで「月面基地の条件ではこの材料は燃えるか？」を推定する。微小重力と通常重力の結果から、部分重力の範囲を「上下の境界」として示す。
- **主な機能**
  - 燃焼限界マップ（横軸 = 気流速度、縦軸 = 酸素濃度、色 = 火炎の広がり速度）
  - 材料選択（綿、Nomex、PMMA、シリコーンなど実験で使われたもの）
  - 「微小重力」「1G」の2条件の結果から、月（1/6G）・火星（約3/8G）の範囲を帯で示す
  - 予測の不確かさの表示と、「部分重力データは将来のLUCI / FM2で補完予定」の注記
- **使用データ**: PSI（BASS, BASS-II, Saffire）、NASA-STD-6001 関連の材料燃焼性試験の公開情報
- **技術スタック例**: Python（scikit-learn のロジスティック回帰 / ガウス過程）、Plotly
- **差別化ポイント**: 課題の2つ目の目標「火災シナリオの予測モデリングを支えるデータ抽出」に正面から取り組み、高酸素の月面基地という最新の文脈に結びつける
- **MVP範囲（2日）**: 材料2〜3種、2変数の境界マップ
- **リスク・注意点**: データ点が少ないので過学習に注意。予測ではなく「データに基づく目安」と表現する

## 案4: Fire Scenario Simulator — 「宇宙船で火災発生」を時系列で追う学習シミュレーター

- **コンセプト**: 「月面与圧ローバー内でケーブルが過熱」などのシナリオを選ぶと、**予防 → 検知 → 消火**の各フェーズで関連する実験知見がタイムラインで提示される。学生が微小重力の燃焼の特殊性（球状の炎、煙の挙動、冷炎）を学べる教材。
- **主な機能**
  - シナリオ選択（宇宙船・ISS・月面基地・与圧ローバー）
  - フェーズ別に関連実験を提示: 予防（BASS/Saffire）、検知（SAME/SAME-R）、消火（FLEX）
  - 「微小重力ではろうそくの炎が青い球になる理由」などのアニメーション解説
  - 過去の実際の事例（Apollo 1、Apollo 13、Mir 火災、Artemis II の煙警報）と教訓
  - SIへの質問ボックス（「この状況でCO₂消火は有効？」→ FLEX の結果を引用して回答）
- **使用データ**: PSI、NASA の事故報告書・公開資料
- **技術スタック例**: React + アニメーション（Lottie / Canvas）、RAG + LLM API
- **差別化ポイント**: 研究データを「シナリオ」という文脈で再構成し、学部生にも理解しやすくする
- **MVP範囲（2日）**: シナリオ2本、各フェーズに関連実験2〜3件
- **リスク・注意点**: 事故の事実関係は公式資料に基づいて記述する。ロケット推進剤の燃焼は対象外と明記

---

## 案5: Space-to-Earth Fire Tech Finder — 宇宙の燃焼研究を地上の防災につなげる

- **コンセプト**: 微小重力燃焼研究の成果が**地上の火災安全**にどう活きるか（細水霧消火器、煙検知器の改良、消防服・空気ボンベなど）を探索できるダッシュボード。研究者だけでなく、消防・建築・防災分野の人が宇宙研究の価値を発見できる。
- **主な機能**
  - 「地上の課題」から検索（例: 高層ビルの煙検知、データセンターの消火、病院の高酸素環境）
  - 関連する宇宙実験と、その知見がどう応用できるかのSI要約
  - NASA Spinoff の事例との関連付け
  - 宇宙 ↔ 地上の対応関係を示すネットワーク図
- **使用データ**: PSI、NASA Spinoff データベース、NTRS
- **技術スタック例**: RAG + LLM API、D3.js（ネットワーク図）、Next.js
- **差別化ポイント**: 課題文の「地上での火災安全への応用」という任意要素を主軸にし、他チームと被りにくい
- **MVP範囲（2日）**: 地上課題5件 × 関連実験・スピンオフのマッピング
- **リスク・注意点**: 主要目標（宇宙探査の火災安全）から外れすぎないよう、案1または案2と組み合わせるのが望ましい
