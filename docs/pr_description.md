# Gale EVA Navigator（NASA Space Apps 2026 / Case 10）

火星の Gale クレーターで、歩いて探査する人（EVA）のためのルート計画・足あとの記録・来た道を戻る案内を作るアプリです。

## 何ができるか
- **ルート計画**: HiRISE の実際の地形データ（約 5 m 間隔、約 3 km 四方）から、傾斜・起伏・歩く速さを使って「安全」「最短」のルートを計算します。AI や機械学習は使っていません（A* 探索）。
- **足あとの記録（通信が切れても動く）**: 衛星測位がない前提で、推測航法で位置を記録し、誤差の円（5 m + 進んだ距離の 3%）を広げます。記録は端末に保存されます。
- **来た道を戻る（とんぼ返り）**: 迷ったとき、足あとを単純化して逆にたどる案内を出します。酸素・バッテリーから帰還の限界も出します。
- **画面**: 左に全体図、右に操作画面（全体図で選んだ範囲だけを拡大）。等高線、斜面リスク、危険エリア、周囲の危険度のヒートマップ、砂嵐の予報（横長の帯）。
- **現場の端末**: ヘルメット表示（HUD）と腕の端末を別ウィンドウで開き、基地と同期します（同じブラウザ内）。
- **計測データの JSON 出力**: 位置、基地からの距離、通信の状態、健康状態をファイルに保存できます。

## 実データとシミュレーションの区別
| 項目 | 区分 |
|---|---|
| 地形（標高・傾斜・等高線・危険エリア） | **実データ**（HiRISE DTM `DTEEC_040770_1755_039280_1755_U01`、背景は Mars Trek） |
| 足あとの移動、砂嵐の予報、健康状態、通信速度 | **シミュレーション**（画面とファイルの両方に明記） |
| 衛星測位 | 将来の測位衛星を**仮定**。圏外では推測航法 |
| 健康状態の注意の目安 | 仮の値。医療的な判定ではない |

## 既知の制限
- 計算範囲は HiRISE の一部（約 3 km 四方）のみ。範囲の外は計算しません。HiRISE 全体（約 31 MB、ルート計算は 0.5 秒以下）へ広げられることは確認済みで、今後の課題です。
- 複数モニターでの全体図 / 操作画面の分離、別端末間の同期は未対応（現在は同じブラウザ内の別ウィンドウのみ）。
- JSON の一部の数値（標高・バッテリー・酸素）が丸められていません。
- 計測データは再読み込みで消えます。
