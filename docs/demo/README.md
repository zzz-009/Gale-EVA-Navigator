# 操作デモ（約 1 分・3 倍速）

アプリの画面を自動で操作し、字幕を重ねるスクリプトです。録画しながら流せば、そのまま発表用のデモ動画になります（アプリのコードは変えていません）。

## 録画のしかた（Windows）
1. `cd app && npm run dev` でアプリを起動し、ブラウザで開く（Chrome 推奨、画面は最大化。サイズは 1600×900 前後がきれい）。
2. 画面を最初の状態にする（計画中の画面。ページを再読み込みすればよい）。
3. `Win + Alt + R` で録画を開始（Xbox Game Bar。保存先は「ビデオ → キャプチャ」）。
4. `F12` → **Console** を開き、[autoplay_demo.js](autoplay_demo.js) の中身を貼り付けて Enter。
   - 「貼り付けを許可」と聞かれたら、`allow pasting` と入力して Enter。
5. 約 55 秒で終わる。終わったら `Win + Alt + R` で録画を止める。DevTools を開いたままだと映るので、貼り付けたあとに **F12 でとじる**（スクリプトは動き続ける）。
6. やり直すときは、ページを再読み込みして 2 から。途中でやめるときは Console で `__galeDemo.stop()`。

## 流れと字幕（合計 約 55 秒）
| 秒 | 画面 | 字幕 |
|---|---|---|
| 0–5 | 計画中（安全ルート 2.8 km） | ① 基地で計画：実際の火星の地形（HiRISE）から、安全ルートを自動で計算 |
| 5–10 | 周囲の危険度のヒートマップ | 危険度のヒートマップを重ねて、周囲のリスクを確認 |
| 10–16 | 出発。足あとを記録（3 倍速） | ② 出発：足あとを記録（3 倍速・移動はシミュレーション） |
| 16–23 | 圏外。誤差の円が広がる | ③ 通信が途切れた（圏外）：衛星なしの推測航法で記録を続け、誤差の円が広がる |
| 23–28 | 通信復帰 | 通信が復帰：端末にたまった記録を、古い順に送る |
| 28–33 | 迷った | ④ 道に迷った！ 足あとを逆にたどる「来た道を戻る」へ |
| 33–46 | 来た道を戻る | ⑤ 来た道を戻る：足あとと目印で案内。酸素・バッテリーから帰還の限界を確認 |
| 46–51 | 締め | 通信がなくても、歩いて、戻れる。 |

## 速度や長さを変える
- `autoplay_demo.js` の `sleep(...)`（ミリ秒）で、各場面の長さを変えられる。
- 倍速は `'×3'` を `'×1'`（実時間）か `'×8'`（最速）に変える。×8 だと移動が 4 秒ほどで終わるので、圏外の場面（`sleep(7000)`）を短くする。

## 注意
- 足あとの移動、砂嵐、健康、通信はシミュレーションです。字幕でも「シミュレーション」と言っています。
- アプリが「迷う場面あり」の移動シミュレーションの設定のとき（初期設定）に合わせて作ってあります。JSON の位置情報に切り替えていると場面が変わります。
