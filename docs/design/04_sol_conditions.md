## 1. 目的
着陸・活動の候補地点と日程を選ぶと、**太陽と地球がその場所の地平線に対してどこにあるか**、**発電（日照）と地球との直接通信がどれだけできるか**を数秒で比べられるようにする。日程がずれたときの再評価も速くする。

## 2. 利用者と場面
| 利用者 | 場面 | 欲しい答え |
|---|---|---|
| ミッションの計画担当 | 候補地点を絞る | 「どの地点が、日照と通信の両方で有利か」|
| 計画担当 | 打ち上げ・到着が遅れた | 「到着が ◯ Sol ずれると条件はどう変わるか」|
| 科学チーム | 科学的に面白い地点を推したい | 「その地点は工学的に成り立つか」|
| 学生・一般 | 学ぶ | 「火星の空では太陽と地球がどう動くか。地球とどう違うか」|

```
│ ┌Gale──────────┐┌Jezero────────┐┌InSight───────┐                     │
│ │小さいパノラマ   ││              ││              │                     │
│ │太陽 34°・日没まで 5h12m        ││              │                     │
│ │地球 12°・地球が沈むまで 1h40m  ││              │                     │
│ │日照 12.1 h / 地球 4.3 h / 両方 4.0 h          │                     │
│ └──────────────┘└──────────────┘└──────────────┘                     │
│ 日時: [2027-03-10 06:00 UTC]  ◀ −1 Sol  +1 Sol ▶   [延期カレンダー]    │
└────────────────────────────────────────────────────────────────┘
```
- カードをクリックすると、大きいパノラマ（横軸 方位 0〜360°、縦軸 仰角）とタイムライン（1 Sol の日照・地球の帯）が開く
- 縦軸の範囲は自動: 太陽が高い地点は −10〜+90°、地平線近くを見たいときは拡大ボタン（−5〜+15°）
- **火星の空の特徴**を見せる: 地球は太陽から最大 約47° しか離れないので、パノラマでは地球が太陽を追いかけるように動く

## 5. 計算仕様

### 5.1 太陽と地球の方向（`lib/ephem.ts`）— 任意の地点で、その場で計算する
1. **前処理**（`pipeline/fetch_ephem.py`）: JPL Horizons API で、**火星（499）を対象、地球の中心を観測者**として、次を 1 時間ごとに取得する
   - **太陽直下点**（火星の表面で太陽が真上に来る点）の経度・緯度
   - **地球直下点**（火星の表面で地球が真上に来る点）の経度・緯度
   - 火星と地球の距離
   - 期間: 2026-11-01 〜 2028-12-31（火星の1年 ≈ 687 日をカバー）
   - **取得する観測量の番号と、経度の向き（東向きか西向きか）は、Horizons の公式ドキュメントで必ず確認する**。火星は古い慣習で「西向きが正」の経度が使われることがあり、取り違えると太陽が逆方向に出る
2. **フロント**: 地点の緯度・経度と、直下点の緯度・経度から、その地点での**方位と仰角**を計算する（球面三角法。太陽と地球は十分遠いので、地点の位置のずれは無視してよい）
   - 時刻の間は線形補間する
   - **利点**: 地図をクリックした任意の地点でも、Horizons を呼ばずに即座に計算できる

```ts
// 直下点 (latS, lonS) と地点 (lat, lon) から方位・仰角（度）
function azEl(lat: number, lon: number, latS: number, lonS: number): { az: number; el: number }
```

3. 天体の設定で切り替える: 火星 = Horizons の対象 499、月 = 301

### 5.2 地平線マスク（`pipeline/build_horizon_masks.py`）
- 地点から方位ごと（0.5° 刻み）に直線を伸ばし、地形の見かけの仰角の最大値を地平線とする
  ```
  el(d) = atan( (h(d) − h_obs − d² / (2R)) / d )      火星 R = 3,389.5 km / 月 R = 1,737.4 km
  ```
- 観測者の高さ: 地面 + 2 m。最大距離: 150 km（Gale の外輪山や Mount Sharp は数十 km 先にある）
- 地形データ: **P0 は全球の地形データ**（MOLA、または MOLA と HRSC を合わせたもの。約 200〜460 m）。地平線は遠くの地形で決まるので、粗くてよい。**入手先は実物を確認して `docs/data_notes.md` に記録**
- 火星の大気による屈折は小さいので無視し、画面に「屈折は無視」と表示する
- 地図クリックの地点（地平線を事前計算していない場所）: 最も近い事前計算地点が 5 km 以内ならそれを使い、それ以外は「地形なし（球面の地平線）」と表示する

### 5.3 指標（`lib/metrics.ts`）
| 指標 | 定義 |
|---|---|
| 太陽高度・地球の高度 | 指定時刻の仰角 |
| 日没まで / 地球が沈むまで | 指定時刻から、仰角が地平線マスクの下に入るまでの時間（地球の時間と火星の時間の両方で表示）|
| その Sol の日照時間 | その Sol で太陽が地平線マスクの上にある時間 |
| 地球が見える時間 | その Sol で地球が地平線マスクの上にある時間 |
| 両方そろう時間 | 太陽と地球の両方が上にある時間（発電しながら直接通信できる時間）|
| 合の警告 | 火星から見た太陽と地球の間の角度が、閾値（初期値 3°）より小さい |
| 季節 | Ls。Ls 180〜360° は「砂嵐が起きやすい季節」と表示 |
| 判定 | 日照時間と地球が見える時間のしきい値（UI で変更可）で、良 / 注意 / 不可 |

### 5.4 火星の時刻（`lib/marsTime.ts`）
- NASA GISS の **Mars24** のアルゴリズム（Allison & McEwen 2000）で、地球の時刻 → 火星日（MSD）、MTC、LMST、LTST、Ls を計算する
- Sol 番号はミッションごとの数え方（着陸日を Sol 0）で表示する。着陸日は地点の一覧に持たせる
- **単体テスト**: Mars24 の公式ページの計算例と一致すること

## 7. 検証

| 確認すること | 期待される結果 |
|---|---|
| 太陽の方位・仰角 | 直下点から計算した値と、Horizons で地点を直接指定して取った値の差が 0.5° 以内（3地点 × 3時刻）|
| 経度の向き | Gale で、太陽が東から昇って西に沈み、**地方真太陽時（LTST）の正午ごろに仰角が最大**になる（ずれていれば経度の向きか時刻の計算が間違っている）|
| 地球の動き | 地球が太陽から 47° 以上離れない |
| 火星の時刻 | Mars24 の計算例と一致 |
| 地平線 | Gale の地点で、Mount Sharp の方向（南東〜南）の地平線が高い |
