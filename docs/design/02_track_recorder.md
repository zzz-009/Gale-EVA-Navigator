# 設計書 02 — Contour Track Recorder（歩いた道を等高線の地図に記録する）

> 優先: **P0** / 全体像: [00_overview.md](00_overview.md)
> ユーザーの要望: ①動いた道を等高線で表示・記録 ②それをアプリ内でも表示・記録（火星は通信が途切れるため）

---

## 1. 目的
宇宙飛行士が歩いた道（足あと）を、**等高線の地図の上に**時刻・標高・位置の確からしさと一緒に記録・表示する。**通信がなくても記録が止まらず**、通信が戻ったらまとめて送る。この記録が、03（とんぼ返り）の土台になる。

## 2. 前提: 火星には GPS がない
- 位置は**推測航法**（歩数・向き・加速度から位置を積み上げる）で決め、ずれは**誤差の円**で表す
- 地図の目印と照らし合わせて位置を確定し直すと、誤差の円は小さくなる（03 の P1）
- **デモの移動はシミュレーション**で、画面にそう明記する

## 5. 計算仕様

### 5.1 等高線（前処理 `build_contours.py`）
| 地形データの解像度 | 細い線 | 太い線（標高の数字）|
|---|---|---|
| 2 m 以下（HiRISE）| 5 m ごと | 25 m ごと |
| 約 200 m（代用）| 50 m ごと | 250 m ごと。「等高線は粗い」と表示 |
- 等高線は緯度経度の GeoJSON（`contours.geojson`、属性 `elev_m`、`index`）
- 地図のズームが小さいときは太い線だけ表示する（線が混みすぎないように）

### 5.2 推測航法と誤差（`lib/deadReckoning.ts`）
```
誤差の半径 = 最後に確定したときの誤差 + k × 確定してから進んだ距離
k = 0.03（初期値。UI に式を表示）  確定したときの誤差 = 5 m
```
- 基地を出発するときは「確定」（`src = 'fix'`）

### 5.3 記録の間隔
- 30 秒ごと、または 10 m 進むごと（どちらか早い方）に1点
- 標高は `elev.f32` から、その位置の値を引く（地形データの範囲外は `null`）

### 5.4 予定ルートからのずれ
- 最新の点から予定ルートの線までの最短距離。30 m 以上で警告（「予定ルートから 42 m 外れています」）

### 5.5 通信遮断モード（`lib/commQueue.ts`）
- 圏外: 新しい点は `sent = false` で保存し、未送信の件数を増やす
- 通信可に戻る: `sent = false` の点を古い順に「送信」し（デモでは 0.1 秒ごとに `sent = true` にして件数が減る様子を見せる）、件数を 0 にする
- P1: `viewshed.png`（基地のアンテナの高さ 10 m、宇宙飛行士の高さ 2 m で、地形データから見通しを計算）で、足あとが圏外のマスに入ったら自動で圏外にする

### 5.6 シミュレーションの足あと（前処理 `make_sim_track.py`）
1. 01 の安全なルートに沿って歩く（速さは 01 の 5.3 の式。位置に少しずれを足す）
2. 全体の 60% あたりで、**予定ルートから外れて谷に入り込む**（迷う場面）
3. 推測航法の誤差を 5.2 の式で足していく。基地と、途中の目印1か所で「確定」の点を入れる
4. 出力: `sim_track.json`（`t, lat, lon, src`）。**「シミュレーション」と属性に書く**

## 6. 型
```ts
type TrackPoint = {
  id: string; t_utc: string; sol: number; lmst: string;
  lat: number; lon: number; elev_m: number | null; heading_deg: number;
  err_m: number;          // 誤差の円の半径
  src: 'dr' | 'fix';      // 推測航法 / 目印で確定
  note?: string;
  sent: boolean;
  simulated: true;        // デモではすべて true
};
```

## 7. 検証
| 確認すること | 期待される結果 |
|---|---|
| 等高線と画像 | クレーターの縁で、等高線と HiRISE の画像の地形が一致 |
| 標高 | 足あとの標高が、同じ地点の情報ウィンドウの標高と一致 |
| 保存 | 再読み込みしても、足あと・未送信の件数が残る |
| 距離 | 歩いた距離の合計が、足あとの点の間の距離の合計と一致 |
| 通信遮断 | 圏外の間に記録した点の数 = 未送信の件数 |

## 9. リスク
| リスク | 対策 |
|---|---|
| 高解像度の地形データがない | 200 m の地形データの等高線で代用（粗いと明記）|
| 等高線の GeoJSON が重い | 活動する地域だけに絞り、線を間引く（許容幅 1 m）|
| 「本当に歩いた記録」と誤解される | すべての点に `simulated: true`。画面に「シミュレーション」と常に表示 |
