## 1. 先に確認したいこと（本当にそれでいい？）

1. **全体図の「ドラッグで移動」と「ドラッグで範囲を選ぶ」がぶつかる。** 同じドラッグに 2 つの意味は持たせられない。この設計では:
   - ふつうのドラッグ = 地図の移動（Google マップと同じ）、ホイール = 拡大・縮小
   - **範囲を選ぶ = 「範囲を選ぶ」ボタンを押してからドラッグ**（または **Shift キーを押しながらドラッグ**）
2. **記録中に探査者が選んだ範囲の外へ出ると、操作画面から消えてしまう。** 「範囲の外は映らない」をそのまま守ると、現場で困る。この設計では:
   - 計画中: 選んだ範囲に固定
   - **現場（記録・迷った・とんぼ返り）: 探査者が範囲の端に近づいたら、範囲を自動で探査者の位置へずらす**（範囲の大きさは変えない）。全体図の白い枠も一緒に動く。全体図で範囲を選び直したら、その範囲を使う
3. **今の全体図（左上の小さな地図）と、地図の上の「全体図を表示」ボタンは不要になる**（左半分が全体図になるため）。削除する。U-4 の「計画中 / 現場で全体図の表示を別々に持つ」設定も、基地の画面では使わない（HUD の全体図には残す）
4. 画面の幅が 900 px 以下では、左右に並べると狭すぎる。**上に全体図、下に操作画面**の縦並びにする

## 2. L-1・L-2 表示画面（全体図）

| 項目 | 仕様 |
|---|---|
| 置き場所 | 地図の行の**左半分**（`grid-template-columns: 1fr 1fr`、間に 8 px のすき間）|
| 中身 | **操作画面と同じ図面**: 背景（白黒 / カラー）、等高線、危険エリア、周辺の危険度、ルート、足あと、基地・目的地・目印、現在地。等高線の標高ラベル（U-6）はズーム 15 以上で出る |
| 初期表示 | 活動地域の全体（`fitBounds(region)`）|
| 操作 | ホイールで拡大・縮小、ドラッグで移動、右下の ＋ − ボタン |
| 範囲の選択 | 左上の「**範囲を選ぶ**」ボタンを押すと選択モード（ボタンが青くなり、カーソルが十字）。ドラッグで四角を描くと、その範囲が操作画面に映る。選び終わったら選択モードは自動で切れる。**Shift + ドラッグ**でも選べる（Leaflet の `boxZoom` は無効にし、自前で四角を描く）|
| 選んだ範囲の表示 | **白い枠**（太さ 2、塗りなし）。枠の外は少しだけ暗くする（黒、不透明度 0.25）|
| 小さすぎる範囲 | 一辺 100 m 未満の四角は無視し、「もう少し大きく選んでください」を 2 秒表示 |
| 初期の選んだ範囲 | 選んでいるルートを囲む四角 + 周り 150 m |
| ルートを選び直したとき | 範囲を、新しいルートを囲む四角に更新する |

## 3. L-3 操作画面

| 項目 | 仕様 |
|---|---|
| 置き場所 | 地図の行の**右半分** |
| 表示範囲 | 全体図で選んだ範囲に `fitBounds`。**`setMaxBounds(選んだ範囲)` + `maxBoundsViscosity: 1`** で、範囲の外へは動かせない |
| 拡大 | **最小ズーム = 選んだ範囲がちょうど収まるズーム**（それより引けない）。最大ズーム = 16 |
| 範囲の外を映さない | 選んだ範囲の外側を、**不透明の黒の多角形（世界全体の四角から、選んだ範囲を穴として抜いた形）**で覆う。専用の pane（`zIndex 640`、`pointer-events: none`）に置く。これで、拡大・移動しても範囲の外は見えない |
| 今の機能 | 今のメインの地図の機能はすべてここに残す（クリックで情報の吹き出し、危険エリアのクリック説明、目的地のドラッグ、レイヤーボタン、現在地ボタン、HUD 表示ボタン、凡例、座標と標高の表示）|
| 現場での自動追従 | 1 章の 2 のとおり。探査者が範囲の端から 15% 以内に入ったら、範囲の中心を探査者へ移す |

### 2 つの地図の連携
- 全体図で範囲を選ぶ → 操作画面が切り替わる（0.4 秒で移動）
- 操作画面は範囲の中に閉じ込められているので、操作画面の動きで全体図の枠は変わらない（枠 = 選んだ範囲）
- **操作画面が今映している場所**も、全体図に**点線の細い枠**で表示する（選んだ範囲の中のどこを拡大しているかが分かる）

## 4. L-4 文字の表示（地図の下にスクロール）

| 今の場所 | 新しい場所 |
|---|---|
| 指標カード（EVA 安全スコア〜科学観測地点）の横の列 | **そのまま**（地図の上）|
| 右のパネルの中身（HUD を別ウィンドウで開く、目的地までの距離、位置の取得元、ルート候補、ルートの解説、記録・迷った・とんぼ返りのパネル、指標とデータの説明）| **2 つの地図の直下**。カード状に横に並べ、幅が足りなければ折り返す（`grid-template-columns: repeat(auto-fill, minmax(320px, 1fr))`）|

- ページ全体を縦にスクロールできるようにする（今は `overflow: hidden` で画面に固定されている）
- **地図の行の高さは `62vh`（最小 420 px）**。スクロールしても地図の大きさは変わらない
- 右のパネル（`aside.side`）の 360 px の列はなくす
- 並び順: 現場のパネル（記録・迷った・とんぼ返り）があるときはそれを先頭に、計画中は「目的地までの距離 → ルート候補 → ルートの解説 → 位置の取得元 → HUD・腕の端末 → 指標とデータの説明」
- 「このルートで出発」「迷った」「来た道を戻る」のような**大事なボタンは、スクロールしないと押せない位置にならないよう**、パネルの先頭に置く

## 5. L-5 砂嵐の予報（横長、天気予報風）

- 置き場所: **2 つの地図のすぐ下、文字のカードより上**。幅いっぱいの横長の帯
- 左端の縦長のパネル（今の `DustPanel`）と、地図の上の「砂嵐の予報」ボタンはなくす

```
┌砂嵐の予報（シミュレーション）─ 季節 Ls 284°（砂嵐が起きやすい季節）──────────────────────┐
│ 現在   +1h   +2h   +3h   +4h   +5h   +6h   +7h   +8h  …  +12h   │ [小さい地図]          │
│  ○     ○     ◔     ◔     ◑     ◑     ◕     ●     ●        ●     │ 選んだ時刻の          │
│ 43km  36km  30km  23km  17km  10km   4km  到達   中        中     │ 砂嵐の位置            │
│                                     ⚠ 約 7 時間後に活動地域に到達 │                      │
│ ※ 訓練用のシミュレーションです（実際の予報ではありません）                              │
└──────────────────────────────────────────────────────────────────────────┘
```
| 項目 | 仕様 |
|---|---|
| 1 時間ごとのマス | 13 マス（現在〜+12h）を横に並べる。各マスに、時刻・**近さのアイコン**・活動地域までの距離（`nearest_km`）|
| 近さのアイコン | 距離 30 km 以上 = ○、15〜30 = ◔、5〜15 = ◑、0〜5 = ◕、0（到達）= ●。色は茶色 `#b5651d`、到達したマスは背景を薄い茶色にする |
| 選んだ時刻 | マスをクリックすると、その時刻を選ぶ（右の小さい地図が切り替わる）。▶ で 1 秒に 1 時間ずつ進む |
| 右の小さい地図 | 今の砂嵐の地図（Gale 周辺 約 200 km、活動地域の四角、砂嵐の円と矢印）を幅 260 px で置く |
| 到達の警告 | 到達する時刻があれば、帯の中とヘッダーに「⚠ 約 ◯ 時間後に活動地域に到達（シミュレーション）」|
| 表記 | 見出しの「（シミュレーション）」と、下の注記は**必ず残す**。季節（Ls）は実際の計算値 |
| 折りたたみ | 帯の右上に「—」。折りたたむと見出しの 1 行だけになる |
| 幅が狭いとき | 13 マスは横にスクロールできるようにする（`overflow-x: auto`）|

## 7. 完了条件

1. 地図の行の左半分が全体図、右半分が操作画面。900 px 以下では縦並び
2. 全体図でホイール・ドラッグ・＋−が使え、「範囲を選ぶ」または Shift + ドラッグで範囲を選ぶと、操作画面がその範囲を拡大して映す

5. 指標カードの横の列は地図の上のまま。それ以外の文字はすべて地図の下にあり、ページを縦にスクロールして見られる
6. 砂嵐の予報が、地図の下の横長の帯（13 マス）で表示され、「シミュレーション」の表記が 2 か所にある
7. 今の機能（ルート、記録、通信遮断、迷った、とんぼ返り、HUD、腕の端末、端末保存）がすべて動く
