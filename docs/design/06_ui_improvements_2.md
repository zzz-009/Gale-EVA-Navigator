## 2. U-7 傾斜リスク（危険エリア）をクリックすると、何が危険かを説明する

### 動き
- 危険エリア（オレンジの多角形）を**クリック**すると、吹き出しが開く。今の、マウスを乗せたときの短い表示（ツールチップ）は残す
- 危険エリアのクリックは、地図のクリック（仮マーカーを置く）に**伝わらないようにする**（`L.DomEvent.stopPropagation`）

### 吹き出しの中身（テンプレート。`app/src/hazardText.ts` を新規作成）
```
急斜面（20° 超）｜通行不可
最大 27.4°・平均 22.1°・面積 0.41 ha

何が危険か
・傾斜が 20° を超えていて、宇宙服を着た状態では登り下りできない設定です
・足を滑らせると止まりにくく、転倒・滑落のおそれがあります
・ルートはこのエリアを通りません

根拠: HiRISE の地形データ（5 m 間隔）の傾斜から自動で作成。5 m より小さい岩は含まれません
```

| level | 見出し | 「何が危険か」の文 |
|---|---|---|
| `no_go` | 急斜面（20° 超）｜通行不可 | 上の 3 行 |
| `limited` | 急な斜面（15〜20°）｜注意 | ・通行はできますが、歩く速さが落ちます（平地の約 5〜6 割）<br>・斜面を横切ると、横に転倒するおそれがあります。まっすぐ登り下りするか、迂回してください<br>・EVA 安全スコアでは、この中を通る長さが減点されます |

- 「20°」「15°」は `region.json` の `slope_max_deg`・`slope_limited_deg` から読む（直書きしない）
- 「平地の約 5〜6 割」は Tobler の式（`core` の `walkSpeed`）で 15°・20° の速さ ÷ 平地の速さを計算して出す（直書きしない）
- **「20° 以上は登れない」は、このアプリの設定値**であることが分かる言い方にする（「〜できない設定です」）

### 完了条件
- 危険エリアをクリックすると、上の吹き出しが出る。仮マーカーは置かれない
- `no_go` と `limited` で文が変わる
- 数値（傾斜の上限、速さの割合）がコードに直書きされていない

## 3. U-5 周辺の危険度は、何を基準に危険なのかを示す

### 3.1 基準の説明パネル
- 凡例の「周辺の危険度: 低 ━━ 高」の横に **「?」ボタン**を置き、押すと説明パネルが開く
- 中身:
```
周辺の危険度の決め方
危険度 = 傾斜の項 + 起伏の項（最大 1）
 ・傾斜の項 = (傾斜 ÷ 20°)²   … 上限の 20° に近いほど急に大きくなる
 ・起伏の項 = 0.5 × 起伏      … 周りより凸凹している（岩や段差が多い）ほど大きい
 ・傾斜 20° 超（通行不可）は 1
ルートの計算（安全ルート）でも、同じ考え方で危険な場所を避けています

色      危険度      目安
塗らない 0〜0.15    平らで歩きやすい
青緑    0.15〜0.35  少し傾いている
黄      0.35〜0.6   傾斜 12° 前後。速さが落ちる
オレンジ 0.6〜0.85  傾斜 15° 以上。注意して進む
赤      0.85〜1     上限に近い、または通行不可
```
- 「傾斜 12° 前後」などの目安は、起伏 0 のときに各境界の危険度になる傾斜（`20 × √危険度`）を計算して出す

### 3.2 クリックした地点の内訳
- 地図をクリックしたときの吹き出し（今の「標高・傾斜」）に、**危険度とその内訳**を足す:
```
危険度 0.72（オレンジ）
 = 傾斜 16.0° による 0.64 + 起伏 0.16 による 0.08
```
- 計算は Claude が `core` に追加した **`riskAt(grid, slope, i)`** を使う（下記）。**`heatmap.ts` の中の式も `riskAt` に置き換えて、ヒートマップと説明の計算を 1 か所にそろえる**

### 3.3 `core` の関数（Claude が実装済み）
```ts
riskAt(grid: Grid, slope: Float32Array, i: number, slopeMaxDeg = 20): {
  risk: number;        // 0〜1
  slopeTerm: number;   // (傾斜/上限)²
  roughTerm: number;   // 0.5 × 起伏
  blocked: boolean;    // 傾斜が上限を超える
  band: 0 | 1 | 2 | 3 | 4; // 0 塗らない / 1 青緑 / 2 黄 / 3 オレンジ / 4 赤
} | null               // 値なしのマスは null
RISK_BANDS: { max: number; label: string }[]   // 色の境界（0.15, 0.35, 0.6, 0.85, 1）
```

### 完了条件
- 「?」で説明パネルが開閉する
- 地図のクリックで、危険度と内訳が出る（傾斜の項 + 起伏の項 = 危険度）
- ヒートマップの色と、クリックした地点の帯（青緑〜赤）が一致する

## 4. U-6 等高線・標高に数値を表示する

### 4.1 等高線のラベル
- **太い等高線（25 m ごと）**に、標高の数字を付ける（例: `−4,250 m`）
- 付け方: 太い線に沿って **約 400 m ごと**に 1 つ（線の長さに沿って距離を足していき、400 m を超えた点に置く）。短い線（400 m 未満）は、真ん中に 1 つ
- 表示: `L.marker` + `L.divIcon`（文字だけ。背景は半透明の黒、文字は白、11 px）。**回転はしない**（実装を簡単にするため）
- **ズーム 15 以上のときだけ表示**する（ズームが小さいと文字で地図が埋まるため）。ズームが変わったら表示・非表示を切り替える
- 等高線のレイヤーを消したら、ラベルも消す

### 4.2 マウス位置の標高・傾斜
- 地図の下の座標の表示（今の `4.7204°S, 137.3890°E`）に、**標高と傾斜**を足す:
  `4.7204°S, 137.3890°E｜標高 −4,312 m｜傾斜 7°`
- `elevAt(grid, p)` と、`latLonToCell` → `world.slope[idx]` で求める。活動地域の外では標高・傾斜を出さない
- マウスが動くたびに計算してよい（1 マスを引くだけなので軽い）
- スマホ（マウスがない）では、地図の中心の値を表示する

### 完了条件
- ズーム 15 以上で、太い等高線に標高の数字が出る。ズーム 14 以下では出ない
- マウスを動かすと、標高と傾斜の数字が変わる。クリックしたときの吹き出しの値と一致する

## 5. U-8 砂嵐の予報パネル（1 時間ごと、全体図の下）

### 5.1 先に確認したいこと（本当にそれでいい？）
**火星の砂嵐を「1 時間ごとに予報する」公開データは、NASA にもありません。** 実在するのは次のようなものです。
| 実在するもの | 中身 | 使えるか |
|---|---|---|
| 周回機 MRO の MARCI による全球の天気の画像 | 1 日 1 回程度の全球の画像（週ごとの火星の天気報告として公開）| 1 時間ごとの予報ではない |
| 季節（太陽黄経 Ls）| Ls 180〜360° は砂嵐が起きやすい季節 | **使える**（`core` の `marsTime` で計算済み）|
| 火星の気候のデータベース | 平均的な状態（気候値）| 予報ではない |

そのため、**1 時間ごとの発生地は「シミュレーション（訓練用のシナリオ）」として表示し、画面にそう明記する**設計にします。季節（Ls）だけは実際の計算値を出します。発表では「将来、周回機の観測と予報を受け取ったときの表示のしかた」と説明してください。本物の予報のように見せると、科学妥当性で大きく減点されます。

### 5.2 縮尺
- 砂嵐は数十〜数百 km の広さがあり、活動地域（3 km 四方）は**まるごと入ってしまう**。そのため、パネルは**活動地域より広い範囲（Gale クレーター周辺 約 200 km 四方）**を表示し、その中に活動地域を小さな四角で示す

### 5.3 置き場所と大きさ
- **全体図（ミニマップ）のすぐ下**（同じ左側の列、幅 200 px、地図の部分は高さ 150 px）
- 全体図と同じく、U-4 の設定に従う（計画中は折りたたみ、現場では開く）。**全体図とは別に**折りたためる
- 地図の高さが足りないとき（画面の高さ 700 px 以下）は、初めから折りたたむ

### 5.4 中身
```
┌砂嵐の予報（シミュレーション）────── — ┐
│ [Gale 周辺 約 200 km の地図]            │
│   茶色の半透明の円 = 砂嵐（濃いほど強い）│
│   白い小さな四角 = 活動地域              │
│   矢印 = 砂嵐が動く向き                  │
├─────────────────────────────────┤
│ 現在 +1h +2h +3h ... +12h  [▶]        │ ← 時間のスライダー（1 時間ごと）
│ +3h: 活動地域まで 18 km（接近中）        │
│ 季節: Ls 284°（砂嵐が起きやすい季節）    │ ← 実際の計算値
│ ※ 予報は訓練用のシミュレーションです     │
└─────────────────────────────────┘
```
- 背景: Viking の全球タイル（Mars Trek）。ズームは範囲が収まる値で固定、操作は無効（全体図と同じ作り）
- 時間のスライダー: 0〜12（1 時間ごと）。▶ で 1 秒に 1 時間ずつ進む
- **活動地域に砂嵐が届く時刻**があれば、パネルの下と、ヘッダーの宇宙天気の位置に「⚠ 約 ◯ 時間後に砂嵐が活動地域に到達（シミュレーション）」を出す
- 時刻は、ヘッダーの火星の時刻（Sol・LMST）と同じ起点から数える

### 5.5 予報データ（Claude が `core` に実装済み）
```ts
dustForecast(opt: {
  seed: number;            // 同じ seed なら毎回同じシナリオ（デモで再現できる）
  center: LatLon;          // 活動地域の中心
  hours?: number;          // 12
}): {
  frames: { hour: number; cells: { lat: number; lon: number; radius_km: number; intensity: number }[] }[];
  arrival_hour: number | null;   // 活動地域が初めて砂嵐の中に入る時刻（なければ null）
  nearest_km: number[];          // 各時刻の、最も近い砂嵐の縁までの距離（km）
  bounds: [[number, number], [number, number]];  // パネルに表示する範囲
  note: string;            // 「訓練用のシミュレーション」の注記
}
```
- 砂嵐は 3 個。風の向きに沿って移動し、時間とともに大きさ・強さが変わる
- **デモでは `seed: 2` を使う**（活動地域から 43 km の砂嵐が一定の速さで近づき、7 時間後に到達する。「予報を見て早めに戻る」流れが見せやすい。Claude が種ごとの到達時刻を確認済み）
- `nearest_km[h]` = h 時間後の、活動地域の中心から最も近い砂嵐の縁までの距離（km、中に入っていれば 0）。パネルの「活動地域まで ◯ km」に使う
- 強さ `intensity`（0〜1）→ 円の不透明度 `0.15 + 0.45 × intensity`、色 `#b5651d`（茶色）

### 5.6 完了条件
- 全体図の下に、砂嵐の予報パネルが出る（現場では開く、計画中は折りたたみ）
- スライダーと ▶ で、1 時間ごとに砂嵐の位置が変わる
- 活動地域に届く時刻があれば警告が出る
- 「シミュレーション」の表示が、パネルの見出しと注記の 2 か所にある
- 季節（Ls）が表示される
