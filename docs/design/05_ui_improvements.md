## 3. U-1 周辺の危険度ヒートマップ

### 3.1 何を見せるか
「今いる場所の周り、どこが歩くと危ないか」を、色の濃淡で一目で見せる。危険エリア（多角形）は「通ってはいけない場所」、ヒートマップは「通れるけど注意が必要な度合い」。

### 3.2 中心の決め方（「表示している箇所」）
| モード | 中心 |
|---|---|
| 記録中・迷ったとき・とんぼ返り | **探査者の位置**（`backPos ?? pos`）|
| 計画中 | **地図の中心**（`map.getCenter()`）。地図を動かし終えたとき（`moveend`）に更新 |

- 中心が活動地域の外なら、ヒートマップは出さない

### 3.3 危険度の計算（マスごと、0〜1）
ルートの計算（`core/src/astar.ts` の `risk`）と同じ考え方にそろえる:
```
risk = min(1, (slope / 20)² + 0.5 × rough)
傾斜 20° 超（通行不可）は risk = 1
```
- `slope` = `world.slope[i]`（度）、`rough` = `world.grid.rough[i]`（0〜1）
- **式は「指標とデータの説明」パネルに 1 行で書き足す**

### 3.4 描き方
1. 中心のマス `(c0, r0)` から **半径 400 m**（= 約 80 マス）の正方形を切り出す
2. `<canvas>`（幅・高さ = 切り出したマスの数）に、1 マス = 1 画素で色を塗る
3. 色（下の表）。**中心からの距離が半径の 70% を超えたら、外へ行くほど透明にする**（周辺だけを表示していることが分かるように、ふちをぼかす）
4. `canvas.toDataURL()` を `L.imageOverlay` で、切り出した範囲（緯度経度）に重ねる。ぼやけないよう、画像は CSS で `image-rendering: pixelated` にしない（なめらかでよい）
5. 重ねる順番: **陰影・傾斜の詳細より上、等高線・危険エリア・ルートより下**（Leaflet の `pane` を 1 つ作り、`zIndex` を 350 にする）

| risk | 色 | 不透明度 |
|---|---|---|
| 0〜0.15 | 塗らない | 0 |
| 0.15〜0.35 | `#5dcaa5`（青緑）| 0.25 |
| 0.35〜0.6 | `#fac775`（黄）| 0.40 |
| 0.6〜0.85 | `#ef7f62`（オレンジ）| 0.50 |
| 0.85〜1 | `#e24b4a`（赤）| 0.60 |

### 3.5 更新のタイミング（重くしないため）
- 中心が **20 m 以上動いたときだけ**描き直す（記録の再生は 1 秒に 18 点進むので、毎回描き直すと重い）
- 計画中は `moveend` のたびに描き直す
- 160 × 160 マスの塗りは 1 回 数 ms で終わる見込み。**100 ms を超えたら半径を 300 m に下げる**

### 3.6 操作と表示
- 地図右上のレイヤーボタンに **「周辺の危険度」** を追加（初期値: オン）。今の「傾斜の詳細」（地域全体の 4 段階）とは別物
- 凡例（左下）に「周辺の危険度: 低 → 高」の色の帯を足す
- ヒートマップの上にマウスを乗せても何も出さない（`interactive: false`）

### 3.7 コードの置き場所
| ファイル | 中身 |
|---|---|
| `app/src/heatmap.ts`（新規）| `renderRiskHeat(world, center, radius_m): { url: string; bounds: [[s, w], [n, e]] } \| null`（canvas に塗って dataURL と範囲を返す。DOM の canvas を使うので `app/` に置く）|
| `mapController.ts` | `setHeat(img: { url; bounds } \| null)`（`L.imageOverlay` を差し替える）と、`setLayer('heat', on)` |
| `App.tsx` | 中心を決め、20 m 以上動いたら `renderRiskHeat` → `setHeat` |

### 3.8 完了条件
- 記録を再生すると、探査者の周りのヒートマップが一緒に動く
- 崖（危険エリア）の近くは赤〜オレンジ、平らな場所はほぼ透明
- 計画中は、地図を動かすと中心が変わる
- 「周辺の危険度」ボタンで消せる
- 再生がカクつかない（体感で以前と同じ速さ）

## 4. U-2 ミニマップ（画面の左側に、現在地とルートを縮小表示）

### 4.1 何を見せるか
メインの地図を拡大していても、**「活動地域の全体のどこにいて、ルートのどこまで来たか」**がいつでも分かるようにする。迷ったときに特に役立つ。

### 4.2 位置と大きさ
- メインの地図の**左上**（`mapwrap` の中、上・左から 10 px）。今の左上は空いている（レイヤーボタンは右上、凡例は左下）
- 大きさ: **200 × 200 px**。角丸 8 px、枠線は `var(--border)`、背景は不透明
- 右上に小さい「—」ボタンで折りたたみ（折りたたむと「全体図」ボタンだけ残る）
- **画面幅 900 px 以下では初期状態を折りたたみ**にする

### 4.3 中身
| 要素 | 描き方 |
|---|---|
| 背景 | 2 つ目の Leaflet の地図（`CRS_MARS`）。HiRISE のタイルだけ（Viking は不要）。**活動地域の全体が収まるズームで固定**（`fitBounds(region)`）。ドラッグ・ズーム・ボタンはすべて無効 |
| 基地 | 白い点 |
| 目的地 | 紫の点 |
| 選んでいるルート | ルートの色で細い線（2 px）|
| 足あと | 白い線（2 px）|
| 現在地 | 青い点（とんぼ返り中は `backPos`、それ以外は `pos`）|
| メインの地図が見ている範囲 | 白い四角の枠（`L.rectangle`、塗りなし）。メインの地図の `move` のたびに更新 |

### 4.4 操作
- ミニマップを**クリック**すると、メインの地図がその地点へ移動する（`map.panTo`）
- それ以外の操作は受け付けない

### 4.5 コードの置き場所
| ファイル | 中身 |
|---|---|
| `app/src/miniMap.ts`（新規）| `class MiniMap { constructor(el, region, onClick); setRoute(coords, color); setTrack(points); setExplorer(pos); setViewport(bounds); setSites(base, targets); destroy() }` |
| `App.tsx` | `<div className="minimap">` を `mapwrap` の中に置き、MiniMap を作る。メインの地図の `move` を受けて `setViewport` |
| `mapController.ts` | メインの地図の表示範囲が変わったら知らせるコールバック（`onView(bounds)`）を追加 |

### 4.6 完了条件
- メインの地図をズーム・移動すると、ミニマップの白い枠が追従する
- 記録・とんぼ返りの再生中、ミニマップの青い点と足あとが動く
- ミニマップをクリックすると、メインの地図がそこへ移動する
- 折りたたみ・展開ができ、900 px 以下では初めから折りたたまれている
- ミニマップが凡例・レイヤーボタン・ズームボタンと重ならない

## 4b. U-4 計画中は隠すのを初期設定にし、任意で表示できるようにする（2026-11-14 15:45 追加）

### 背景
計画中はメインの地図が地域全体を表示しているので、①ヒートマップは中央の 400 m だけに色が付き意味が伝わりにくい、②ミニマップはメインの地図とほぼ同じ内容になる（Claude のレビューの相談 3・4）。**ユーザーの判断: 計画中は隠すのを初期設定とし、利用者が任意で表示に切り替えられるようにする。**

### 仕様
「計画中」と「現場（記録中・迷ったとき・とんぼ返り）」で、**表示の設定を別々に持つ**。

| 項目 | 計画中の初期値 | 現場の初期値 |
|---|---|---|
| 周辺の危険度（ヒートマップ）| **非表示** | 表示 |
| 全体図（ミニマップ）| **折りたたみ** | 開く（画面幅 900 px 以下では折りたたみ）|

- 計画中に「周辺の危険度」ボタンを押す / 「全体図」を開くと、**計画中の設定だけ**が変わる。現場の設定は変わらない（逆も同じ）
- モードが計画 ↔ 現場で切り替わったら、そのモードの設定を適用する（例: 計画中に全体図を開いていなくても、出発すると全体図が開く）
- 設定はこのページを開いている間だけ覚える（再読み込みで初期値に戻ってよい。端末保存は不要）
- レイヤーボタンの「周辺の危険度」の見た目（オン / オフ）は、今のモードの設定を表示する

### 実装の目安（`App.tsx`）
```ts
type ViewScope = 'plan' | 'field';
const scope: ViewScope = mode === 'plan' ? 'plan' : 'field';
const [heatOn, setHeatOn] = useState<Record<ViewScope, boolean>>({ plan: false, field: true });
const [miniOpen, setMiniOpen] = useState<Record<ViewScope, boolean>>(() => ({
  plan: false,
  field: !window.matchMedia('(max-width: 900px)').matches,
}));
// 今の表示: heatOn[scope]、miniOpen[scope]
// 切り替え: setHeatOn((s) => ({ ...s, [scope]: !s[scope] }))
```
- 今の `layers.heat` と `miniCollapsed` を、上の 2 つに置き換える（`layers` の他の項目はそのまま）
- ヒートマップの effect の依存に `layers.heat` の代わりに `heatOn[scope]` を入れる
- ミニマップの作成の effect は `miniCollapsed` の代わりに `!miniOpen[scope]` で判定する

### 完了条件
- 開いた直後（計画中）: ヒートマップなし、全体図は折りたたみ、「周辺の危険度」ボタンはオフの見た目
- 計画中に「周辺の危険度」「全体図」をオンにすると表示される
- 「このルートで出発」を押すと、計画中の設定に関係なく、ヒートマップと全体図が出る（900 px 以下では全体図は折りたたみ）
- 現場で全体図を閉じてから「計画に戻る」→ 計画中の設定が戻る。もう一度出発すると、現場の設定（閉じたまま）が戻る
- 端末保存から復元した場合（現場として始まる）も、現場の設定で表示される
