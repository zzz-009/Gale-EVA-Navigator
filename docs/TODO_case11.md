## 5. 計算仕様

### 5.1 太陽・地球の方位と仰角（T-11）
- JPL Horizons API（`https://ssd.jpl.nasa.gov/api/horizons.api`）の観測者表（OBSERVER）を使う
  - 対象: 太陽 `10`、地球 `399`
  - 観測地点: 月面の座標（`CENTER='coord@301'`、`COORD_TYPE='GEODETIC'`、`SITE_COORD='東経,緯度,高度km'`）
  - 観測量: 方位・仰角（`QUANTITIES='4'`）、**大気による屈折なし**
- **パラメータ名と値は Horizons の公式ドキュメント（API の説明ページ）で必ず確認してから使う**
- 1回のリクエストで取れる行数に上限があるので、必要なら期間を分けて取得する

### 5.2 地平線マスク（T-12）— 地形 + 月の丸み
- 地点から方位ごとに直線を伸ばし、距離 d の地点の標高 h(d) について、見かけの仰角を計算する
  ```
  el(d) = atan( (h(d) − h_obs − d² / (2R)) / d )     R = 1737.4 km（月の半径）
  ```
  その方位の地平線 = 0 < d ≤ 最大距離 の範囲での el(d) の最大値。そのときの d が `dist_km`
- `− d²/(2R)` が**月の丸みによる「沈み込み」**。これがないと遠くの山を高く見積もりすぎる（v1 からの修正点）
- 観測者の高さ: 地面 + 2 m（太陽電池パネルやアンテナの高さを想定。UI に表示する）
- 距離の刻み: 近くは細かく（例: DEM 解像度ごと）、遠くは粗く（距離に比例して広げる）。最大距離は 150 km から始める
- DEM:
  - 南極の地点: LOLA の南極 DEM（PGDA または PDS。高解像度のものを優先）
  - それ以外: LOLA の全球 DEM（解像度は粗くてよい）
  - **入手先・ファイル名は実物を確認して `docs/data_notes.md` に記録する**
- 予備（DEM が間に合わない地点）: 地形なしの球面の地平線（観測者が2 m の高さにいるとき、ほぼ 0°）。UI に「地形なし」と表示する

### 5.3 見えるかどうかの判定（`visibility.ts`）
- 太陽: `sun.el > horizon.el_deg[az の位置]` なら日が当たっている（太陽の中心で判定）
  - P1: 太陽の見かけの半径（約 0.27°）を考え、「一部だけ見えている」割合も出す
- 地球: 同じ方法で判定

### 5.4 指標（`metrics.ts`）— 地点 × 着陸日時ごと
| 指標 | 定義 |
|---|---|
| 太陽高度 | 着陸時刻の `sun.el`（大きく表示する） |
| 日没まで | 着陸時刻から、太陽が最初に地平線の下に入るまでの時間 |
| 地球が沈むまで | 同じく地球について |
| 日照率 | 着陸後 N 日間（初期値 14 日、UI で変えられる）のうち日が当たっている時間の割合 |
| 最長の連続日照 | 同じ期間で、日が当たり続ける最長の時間 |
| 地球が見える割合 | 同じ期間で地球が見えている時間の割合 |
| 発電と通信の両方ができる割合 | 太陽と地球の両方が見えている時間の割合 |
| 判定 | 日照率と地球が見える割合のしきい値（UI で変更可）で、良 / 注意 / 不可の3段階 |

### 5.5 延期カレンダー（`calendar.ts`）
- 基準の着陸日の前後90日の毎日について、5.4 の「判定」と「両方ができる割合」を計算し、色を塗る
- セルをクリックすると、その日のパノラマと指標に切り替わる

### 5.6 「なぜ」の説明（`explain.ts`）— LLM は使わない
- 計算結果からテンプレートで文章を作る。例:
  - 「着陸から 3.2 日後、方位 142° の方向にある 38 km 先の地形が太陽を隠すため日没になる」
  - 「この地点では地球が地平線から最大 4° しか昇らないため、10 km 横に動くだけで通信できる時間が大きく変わる」
  - 「着陸を 7 日延ばすと、日照率が 62% → 31% に下がる」

## 8. （P2）ルート計算の仕様 — v1 から縮小して残したもの

- 対象: 南極の1地域（約10 km 四方、20 m 解像度 = 500 × 500 マス）。LOLA DEM から傾斜・粗さを計算
- 通行不可: 傾斜 > 20°（UI で変更可）
- 1歩のコスト（8近傍、すべての項は 0 以上）:
  ```
  eff  = d × (1 + slope / slope_max)
  risk = d × ((slope / slope_max)² + rough_norm + 0.5 × (1 − illum))
  sci  = d × (1 − science)          science = exp(−PSR の縁までの距離 / 500 m)
  cost = w_e × eff + w_r × risk + w_s × sci
  ```
- ヒューリスティック = 直線距離 × w_e
- プリセット: 最短 (1.0, 0.1, 0) / 最安全 (0.3, 1.0, 0) / 科学最大 (0.3, 0.3, 1.0)
- 説明: 3ルートの差をテンプレートで文章にする（例: 「最安全ルートは最短より 1.2 km 長いが、最大傾斜が 18° → 9° に下がる」）
- `illum`（平均日照率）は PGDA の日照マップ。なければ 0.5 で一定にし、その旨を表示する
